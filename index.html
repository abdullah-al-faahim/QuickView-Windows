FAQ

Windows SmartScreen warns me when I run it. Is it safe?

QuickView isn't code-signed yet, so SmartScreen shows "Windows protected your PC" for new downloads. Click More info → Run anyway. The app is 62 KB, needs no admin rights, makes no network connections, and writes only one optional registry value (Start with Windows).

How does it stay so small and light?

It's native C++ with no runtime and no frameworks. A tiny background part only listens for Space. The viewer starts when you need it, stays warm for 2 minutes after you close it, then exits completely, so nothing heavy sits in memory.

Do I need Photoshop or Illustrator to preview PSD, AI or EPS files?

No. QuickView decodes the flattened image in PSD/PSB files and reads the preview embedded in AI, EPS and INDD files. If Adobe's own preview handler is installed, QuickView uses it for AI files.

Word, Excel or PowerPoint files only show text.

Full-fidelity Office previews come from Microsoft Office's preview handlers. Without Office installed, QuickView falls back to showing the text content of DOCX, XLSX and PPTX files.

How do I make it start automatically, or uninstall it?

Right-click the tray icon and tick Start with Windows. To uninstall, untick it, choose Exit, and delete QuickView.exe. If you used the ZIP installer, run uninstall.ps1 instead.
